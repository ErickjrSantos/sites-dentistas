Criei 3 versões completas para estudar ângulos diferentes de posicionamento: clínica premium estética, centro de implantes high-tech e odontologia de família com foco em acolhimento. Cada site é um HTML standalone pronto para abrir no navegador.

Luxury / Estética

Lumina Smile Studio

Visual claro e sofisticado, com linguagem premium, foco em lentes, clareamento e harmonização do sorriso. Ideal para ticket médio mais alto.

  • Estilo: Stripe + editorial clean

  • Destaque: autoridade visual e diferenciação
