## 2025-02-14 - Repetitive Link Disambiguation and Focus Standards
**Learning:** In dashboards or showcase pages where multiple items have identical call-to-action text (e.g., "Abrir site" or "Abrir preview"), screen reader users may lose context. Adding context-specific `aria-label` attributes to these links significantly improves accessibility. Additionally, since this repo uses static HTML without a build system, standardizing focus indicators with `outline` and `outline-offset` ensures a consistent and accessible keyboard navigation experience across all generated and manual pages.
**Action:** Always include dynamic `aria-label` in generation templates for repetitive links and use the `outline`/`outline-offset` pattern for focus-visible states instead of relying on non-standard shorthand like `ring`.
