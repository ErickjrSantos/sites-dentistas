# Dentistas Moema — Prospect Pack

Pacote comercial organizado para prospecção de clínicas odontológicas em Moema.

## Estrutura

- `data/` — CSV de leads e JSON de entrada
- `docs/` — `spec.md`, `requirements.md`, `tasks.md`
- `drafts/` — HTML base / versões de trabalho
- `previews/` — índice e previews individuais por clínica
- `screenshots/` — capturas de apoio
- `scripts/` — utilitários de geração

## Abrir localmente

- índice dos previews: `previews/index.html`
